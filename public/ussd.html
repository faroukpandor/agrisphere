📟 Every-phone access (R2)

USSD menu — try it here

This simulator drives the exact engine a network / USSD aggregator can mount (standard sessionId + phoneNumber + text request, CON/END responses). Type numbers like a real session: 1 ask · 2 prices · 3 programmes · 4 marketplace · 5 teach · 6 help, then follow the prompts and press # to finish an ask.

How it works for operators

POST /api/ussd with { sessionId, phoneNumber, text } — the engine replies CON … to continue the session or END … to close it. Replies are truncated to stay inside USSD payload limits. The same brain and memory serve the web, WhatsApp and this menu, so lessons taught on any channel are learned once.

📞 Real deployments need a USSD shortcode from a network and an aggregator (e.g. Africa Talking) pointed at this endpoint — that is a partnership item, not code.
