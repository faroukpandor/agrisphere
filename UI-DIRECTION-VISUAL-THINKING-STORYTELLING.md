# Farouk Collective UI Direction — Visual Thinking × Visual Storytelling

This repository adopts the portfolio-wide UI standard. Design the application around **Goal → Source/Idea → Structure → Evidence → Visualise → Decide → Act → Share**.

Take inspiration from visual-thinking and visual-storytelling principles associated with Napkin AI and Gamma AI: clear narrative hierarchy, visual relationships, progressive disclosure, presentation-quality outputs and flexible layouts. **Do not copy their screens, branding, proprietary assets, code or distinctive trade dress.**

Required: immediate purpose, one primary action, editorial whitespace, strong typography, meaningful cards, visual flows/diagrams/timelines/maps where useful, evidence/source/status visibility, useful share/export outputs, responsive accessibility, lightweight portable implementation, and a distinct domain identity.

Shared conceptual patterns: **Workspace/Canvas, StoryCard, VisualNode, EvidenceChip, SourceBadge, WorkflowStep, InsightPanel, DecisionCard, OutputMode, Dossier/Presentation Renderer.**

Do not migrate frameworks merely for aesthetics. Preserve existing architecture unless a justified product requirement demands change. Client-owned or third-party repositories require authorization before implementation changes.

**Release gate:** understandable journey; visualisation adds meaning; evidence is distinguishable from inference; outputs are useful; mobile/accessibility work; product retains its own identity.
